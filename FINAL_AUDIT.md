## 5. Remaining Risks (Ranked)

1. **Linguistic Native Review Risk (Medium)**:
   - *Risk*: Telugu phrases have not been reviewed by a native clinical linguist.
   - *Mitigation*: The phrase library is isolated in `backend/data/phrases_te.json` and clearly stamped as unreviewed draft text. Protected medical tokens (drug names, doses, dates) remain un-translated in Latin/digit script.
2. **Clinical Abbreviation Variations (Low)**:
   - *Risk*: Real-world handwritten discharge notes may use hospital-specific or non-standard abbreviations.
   - *Mitigation*: Any unrecognized token is marked with `UNSPECIFIED` and automatically sent to the Nurse Review Queue rather than guessed.
3. **External LLM Service Dependency (Low)**:
   - *Risk*: If judges disconnect internet access, external OpenAI/LLM endpoints will fail.
   - *Mitigation*: System runs 100% offline using the built-in deterministic rule parser and narrative extractor.

## 9. 5-Line "If a Judge Asks" Cheat Sheet

1. **How is faithfulness guaranteed?**  
   *The AI never writes free text for the patient. It extracts facts into a typed schema with character source spans, renders from reviewed templates, and runs a round-trip diff in English and Telugu before release.*
2. **What happens on an error or ambiguity?**  
   *CareBridge blocks auto-release immediately. If an eye drop has 'OD' or an ungrounded instruction appears, the plan is routed to the Nurse Review Queue where a clinician can accept with override or edit.*
3. **What is unreviewed?**  
   *The Telugu phrase library is in draft form and clearly flagged as needing native review. However, all medical tokens (drug names, doses, dates) are protected and never translated.*
4. **What is not built?**  
   *EHR FHIR integration and WhatsApp delivery were non-goals for Round 1 and belong to the post-hackathon hospital pilot rollout.*
5. **What are the real benchmark numbers?**  
   *On 2,000 discharge summaries: 100.0% medicine recall, 0 hard errors released, Class 4.3 English reading level, 0.0019s latency, and a calibrated 37.1% nurse review abstain rate.*
